# CarGuard Frontend

CarGuard는 **AI 기반 차량 손상 탐지 & 렌터카 관리 서비스**의 프론트엔드입니다.  
사용자가 차량 사진을 업로드하면, 백엔드(Spring Boot + FastAPI)가 YOLO → ViT 파이프라인으로 손상을 분석하고,  
프론트는 **바운딩 박스 + 손상 확률 툴팁**(단일 탐지 시 히트맵 포함)으로 결과를 시각화합니다.

> 🔎 히트맵(Grad-CAM)은 **단일 이미지 손상 탐지 화면에서만** 사용되며,  
> 렌트 시작/반납 배치 플로우에서는 **사용하지 않습니다.**

---

## 1. 주요 기능

### 1) 단일 손상 탐지 (Single Prediction)

- 한 장의 차량 이미지를 업로드해 **현재 손상이 있는지 바로 확인**하는 화면
- 기능
  - 이미지 업로드 → 백엔드에 손상 탐지 요청
  - YOLO 박스를 이미지 위에 오버레이
  - 박스에 마우스를 올리면 **손상 타입별 확률 툴팁** 표시
  - (옵션) FastAPI가 생성한 **Grad-CAM 히트맵**을 토글/투명도 조절로 오버레이

사용 시나리오:  
- “지금 이 사진 한 장으로 손상이 있는지만 빠르게 보고 싶을 때”

---

### 2) 렌트 시작 (Rent Start, 4장 배치)

- 렌터카 대여 시작 시, 차량의 **기존 손상 상태를 기록**하는 화면
- 사용자는
  - 차량 번호
  - 앞/뒤/좌/우 **4장 이미지**(FRONT, REAR, LEFT, RIGHT)
  를 업로드

- 화면 동작
  - 4장 이미지를 한 번에 업로드 (배치 업로드)
  - 백엔드에서 각 이미지에 대한 손상 수를 합산해 **“시작 시 손상 요약”** 반환
  - 요약 정보와 함께:
    - 손상이 없으면: “기존 손상 없음” 안내 메시지/토스트
    - 손상이 있으면: “기존 손상 N건” 안내 + 상세보기 진입 버튼
  - “상세보기” 클릭 시 **렌탈 상세 화면**으로 이동

> 이 단계에서는 “고객 책임이 아닌 기존 손상”을 **명확히 기록**하는 데 집중합니다.  
> 히트맵은 사용하지 않고, 요약 정보와 박스/툴팁 위주로만 활용합니다.

---

### 3) 렌트 종료 (Rent End, 반납)

- 반납 시 차량을 다시 촬영하여, **렌트 시작 대비 추가 손상**이 있는지 확인하는 화면
- 사용자는
  - 렌탈 ID
  - 차량 번호
  - 앞/뒤/좌/우 4장 이미지를 다시 업로드

- 화면 동작
  - 시작 때와 동일하게 4장 배치 업로드
  - 백엔드에서:
    - 반납 시 전체 손상 수
    - 시작 대비 증감(delta, DamageType별 증가량)
  를 반환
  - 프론트에서는 delta 합을 기준으로
    - 추가 손상 0건 → “추가 손상 없음” 토스트/결과 카드
    - 추가 손상 N건 → “추가 손상 N건” 토스트/결과 카드 + 상세보기 버튼

> 이 단계에서는 **“얼마나 늘었는지(delta)”**를 직관적으로 보여주는 것이 핵심입니다.  
> 마찬가지로 히트맵 없이 박스/툴팁 중심으로 UI를 구성합니다.

---

### 4) 렌탈 목록 & 상세 (Rental List & Detail)

#### 렌탈 목록

- 최근 렌탈 세션들을 **리스트 형태로 조회**하는 화면
- 각 행에는 대략 다음 정보가 포함됩니다.
  - 렌탈 ID
  - 차량 번호
  - 상태(IN_RENT / RETURNED 등)
  - 시작/종료 시각
  - 추가 손상 개수 등

#### 렌탈 상세

- 특정 렌탈 ID에 대해 **시작 시점 / 반납 시점**의 상태를 함께 보여주는 화면
- 백엔드에서 전달하는 데이터(요약) 예:
  - startSummary / finishSummary / deltaSummary (손상 타입별 개수)
  - startTotal / finishTotal / newDamageTotal
  - startImages / finishImages (슬롯별 이미지 + 박스/요약)

- 프론트 동작
  - 앞/뒤/좌/우 기준으로 이미지 정렬
  - 각 이미지에 대해:
    - YOLO 박스를 오버레이
    - Hover 시 손상 타입/확률 툴팁 표시
  - 시작 vs 종료 요약/증감을 테이블로 정리해,  
    **어디에서 손상이 새로 생겼는지** 직관적으로 확인 가능
